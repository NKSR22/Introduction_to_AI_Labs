# ปฏิบัติการประกอบหนังสือ ปัญญาประดิษฐ์เบื้องต้น

Notebook ปฏิบัติการ 15 ชุด ประกอบหนังสือ **ปัญญาประดิษฐ์เบื้องต้น** (Introduction to Artificial Intelligence)
โดย นครินทร์ ศรีปัญญา ทุกชุดเปิดและรันบน Google Colab ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมในเครื่อง

## วิธีใช้

1. คลิกชื่อปฏิบัติการในตารางด้านล่าง ไฟล์จะเปิดใน Google Colab (ต้องเข้าสู่ระบบบัญชี Google)
2. เลือก **File → Save a copy in Drive** เพื่อเก็บสำเนาของตนเองก่อนแก้ไข
3. รันเซลล์ทีละเซลล์จากบนลงล่าง (Shift + Enter) หรือ **Runtime → Run all**
4. เซลล์ที่มี `# TODO` คือแบบฝึกปฏิบัติที่ผู้อ่านเติมโค้ดเอง

รายละเอียดการใช้ Colab และ Python เบื้องต้นอยู่ในภาคผนวก ก ของหนังสือ
